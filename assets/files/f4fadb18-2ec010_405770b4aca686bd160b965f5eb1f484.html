01 · Import
📦
IMPORT_ABC
Reads cache/alembic/*.abc, parses avatar_pose_skin.abc, imports and places each object in the hierarchy.
OUT: Avatar → Pose → Skin collections
→
02 · Materials
🎨
ASSIGN_MATERIAL
Detects the mesh type (body, eye, tongue, teeth, brows, skin, spec) and derives the materials from BASE BODY / SKIN / SPEC.
OUT: materials named Avatar_Skin_Type
→
03 · Textures
🧵
IMPORT_TEXTURES
Connects Albedo / Normal / Specular in the shader nodes from Unity_Export. Handles aliases and the Normal (Non-Color) color space.
OUT: finalized shaders
→
04 · Render
🎬
RENDER_BATCH_EXPORT
+ RENDER_SEQUENCE
Isolates each collection (hide_render on everything else), renders a PNG still and/or an animated sequence frame by frame.
OUT: PNG stills + sequences
→
